# AI for HCP Prompt Lab

Web app ประกอบ workshop **P'Hmee Guide to AI 2026: AI Principles & Prompt Engineering สำหรับบุคลากรการแพทย์**
โดย ดร.ภก.วิรุณ เวชศิริ คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์

เปิดใช้งาน: https://wirunw.github.io/aiforhcp/

## มีอะไรบ้าง

รวม prompt จากการบรรยาย 21 การ์ด 5 หมวด ทุกการ์ดมี dropdown และช่องกรอกให้ปรับเงื่อนไข แล้ว prompt เปลี่ยนตามทันที

- **A พื้นฐาน R–T–F**: คำสั่งทั่วไป vs R–T–F, สรุปงานวิจัยใน 1 นาที
- **B ภาพและสื่อ**: โปสเตอร์แนะนำตัวภาษาไทย, Avatar, การ์ตูน 4 ช่อง, Infographic สุขศึกษา
- **C งานคลินิก (เคสสมมติ)**: SOAP/Nursing note, คู่มือผู้ป่วย, Drug check, CQI Fishbone, แบบฟอร์ม → Google Form ด้วย Apps Script
- **D งานบริหาร**: brief ผู้บริหาร, 5 Why, ออกแบบโครงการ AI, ข้อความสื่อสารภายใน, ประเมินความเสี่ยงก่อนใช้ AI
- **E คอนเทนต์และค้นคว้า**: บทความ, โพสต์ Facebook, สคริปต์วิดีโอสั้น, แผนการตลาด, Deep Research

ผู้เข้าอบรมกรอกวิชาชีพครั้งเดียวด้านบน ระบบจะเติมบทบาท (Role) ในทุก prompt และดาวน์โหลด "สมุดงาน AI" เป็นไฟล์ Word ได้ท้ายหน้า

## ความเป็นส่วนตัว

ข้อมูลที่กรอกเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ถูกส่งไปที่ใด มีปุ่มล้างข้อมูลสำหรับเครื่องส่วนกลาง
